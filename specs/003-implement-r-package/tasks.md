# Tasks: implement-r-package

Plan.md's one remaining open question (condition-class naming) is
resolved here so every task is implementable without further
clarification: a base class `pkghooks_condition` (always carries a `pkg`
field) with three subclasses — `pkghooks_notice` (load-time, non-fatal),
`pkghooks_error_redirect` (error-time, layered onto an existing error),
and `pkghooks_capability_gap` (capability-gap-time, halt-capable). See
T003-6.

## T003-4: Implement detection logic
- [x] T003-4: Write `bindings/r/R/detect.R` with a non-exported function (e.g.
  `pkghooks_detect_tool()`) that reads
  `system.file("agent-detect-spec", "agents.json", package = "pkghooks")`
  via `jsonlite::fromJSON(simplifyVector = FALSE)`, walks each entry's
  `match` condition tree (leaves: `env_set` via `Sys.getenv(name) != ""`;
  `env_value`/`env_matches` via exact/regex match on
  `Sys.getenv(name)`; `file_exists` via `file.exists(path)`; `no_tty` via
  `!isatty(stdin()) || !isatty(stdout())`; combinators: `anyOf`/`allOf`
  recursively), and returns the `key`/`name` of the first entry (in array
  order) whose `match` evaluates `TRUE`, or `NULL` if none match.

## T003-6: Define the condition-class hierarchy and signaling helper
- [x] T003-6: Write `bindings/r/R/conditions.R` defining an internal helper (e.g.
  `pkghooks_signal(class, pkg, message, ..., call_stop = FALSE)`) that
  constructs a condition of class `c(class, "pkghooks_condition",
  if (call_stop) "error" else "message", "condition")`, always including
  `pkg` as a named field on the condition object (not only interpolated
  into the message), with message text built via `cli::cli_inform()` (for
  non-fatal) or `cli::cli_abort()` (for halting) using `{pkg}`/glue-style
  interpolation. Use three concrete subclasses:
  `"pkghooks_notice"` (non-fatal, load-time), `"pkghooks_error_redirect"`
  (non-fatal, layered onto an existing error at error-time — signalled
  alongside the original error via `rlang::abort(..., parent = original)`
  or an equivalent chained-condition mechanism, not replacing it), and
  `"pkghooks_capability_gap"` (halting, `call_stop = TRUE`, capability-gap
  time).
